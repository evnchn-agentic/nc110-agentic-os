### M1. `hda::poll` is called **once per `Ctl::step`**, but `step` also `delay_ms`-blocks and the ring only holds ~340 ms → guaranteed overrun + permanent desync

`hda::poll(t)` runs at the top of `step`. But `poll` only advances `LAST_POS` up to `pos` once — and `step` is not called on a fixed cadence (it has an `idle_ms` deadline, footer deadline, and commands that take time). More critically, the drain loop:

```rust
let pos = (h.r32(SD + 0x04) as usize & !3) % RING;
while LAST_POS != pos && CLIP_LEN < CLIP_MAX {
    ...
    LAST_POS = (LAST_POS + 4) % RING;
}
```

has **no overrun detection**. The hardware LPIB wraps the 64 KiB ring. If more than `RING` bytes are produced between two `poll` calls (i.e. any stall > ~340 ms: a `syn`/`lcom` command, the `say` path, a long authenticated command reply, or simply `step` being called late), the NIC/HDA has lapped the reader. `LAST_POS != pos` is then true, the loop copies *stale/overwritten* ring bytes and, on the next poll, `pos` may already be ahead again — the reader silently trails forever and records garbage interleaved with real audio, with no error surfaced. The header comment asserts "the ring holds ~340 ms" as if that bounds the gap, but nothing enforces that `poll` runs faster than that. Contrast with the watchdog discipline elsewhere in this kernel (pet-on-progress): here the capture path has no equivalent guard.

Concrete failing scenario: pull-to-talk on, user types `rec`/`lcom` or the Mac issues `aud`, `step` blocks in the encrypted reply; >340 ms elapse; `poll` laps; the clip is corrupted and `PEAK`/`clip_bytes` still report success.

Fix: track producer/consumer with the half/full-ring semantics HDA already provides (`SD_STS` BCIS/FIFO error bits, or a `CBL`-based write position), detect `pos` crossing `LAST_POS` more than the ring, drop the clip, and surface it.

### M2. `map_uc_4k` reuses an already-split PDE it does not own, and *only* for `UC_USED` bookkeeping — the boot page tables case is real

```rust

    &mut *((old & !0xFFF) as *mut Pt) // already split: one of ours
} else {
    ...
    let pt = &mut (*addr_of_mut!(UC_PT))[UC_USED];

    ...
```

The comment says "already split: one of ours", but the code cannot verify that. A boot-page-table (or any firmware/GRUB-created) PDE with `PS=0` pointing at a page table that is **not one of our `UC_PT` slots** is indistinguishable from a prior `map_uc_4k` call. In that case:

- the code indexes into a foreign table and sets `PCD|PWT` on a PTE that belongs to something else (e.g. MMIO that must stay cached, or a DMA buffer), and
- it *overwrites the PDE* with `(pt | 0x3)` where `pt` is the foreign table address — dropping the original PDE flags (US, PWT, PCD, and especially the US bit) to a bare `present|rw`.

Even in the benign "already one of ours" case, the superscript `(pt as *const Pt as u64) | 0x3` unconditionally rewrites the PDE flags to `0x3`, so the first call's `flags` (PWT/PCD from the original PDE) are lost on the second colliding call — the PTE keeps them, but if anything later walks the PDE it sees `present|rw` only. More importantly, `NUM`/`membar` case: two different `map_uc_4k` calls whose 2 MiB regions collide (e.g. HD Audio BAR and NIC register window on the same 2 MiB PDE) share a table, which is the intended design, but the **`UC_USED` counter is incremented on the `else` branch even though the collision branch never decrements or reuses** — fine — the real bug is the unverifiable `PS==0` assumption.

Minimal correct fix: tag our tables (reserve a known array, or store an ownership page/sentinel), and if `old & 1` (present) and `PS==0` and the table isn't ours, **bail (`return false`) rather than mutate** — the early `map_uc_4k(bar)` in `hda::probe` returning `false` is already handled gracefully.

Also note in `hda::probe`:

```rust
let Some((bar, _)) = pci::first_mem_bar(b) else { ... };
...
if !nic::map_uc_4k(bar) {
    kprintln!("hda: no free UC page table");
    return;
}
```

`map_uc_4k` is fine to call for HDA, **but** the HDA BAR page and the NIC BAR page can land in the same 2 MiB region on this chipset; if the *first* caller split the PDE, the second call hits the `PS==0` branch — which is where M2's unverified ownership bites. Under rule (a) a false negative here means the board may not get the self-reset path → **this is the one place I'd upgrade**. The old fixed `delay_ms(1300)` had identical semantics, so it's not a *new* regression — but the tightened (comment-only) claim "proving the timer runs" is weaker than before because there is no second-confirmation sample. Add a second window or check `TMR`/`TCO1_STS` to prove liveness independent of period.

### S2. TCO probe `wdt::pet()` inside the widget dump (`hda::probe` → `dump` loop) is fine *only if* bmctl is not yet running

```rust
for nid in ... {
    wdt::pet();
    ...
    let e = h.verb(cad, nid, 0xF02 << 8 | i as u32)...;
```

`probe` runs from `kmain` before `bmctl` is up, so petting is legitimate there. But `hdadump` (bmctl command) calls `crate::hda::dump()` → `hda::dump` calls `hda::poll`? No — `dump` does not pet. Good. However `hda::probe`'s widget loop pets **unboundedly** (`sub` widget count from codec, iterated with `wdt::pet()` each iteration) and each `verb` spins up to 1000×100 spin loops with no pet inside the inner wait. On a hostile/buggy codec that reports a huge widget count, `probe` can run for a long time petting the watchdog — *during `kmain`, before bmctl*. Since bmctl isn't served yet, this is not a rule-(a) violation, but it is a "new path that pets the watchdog" (none — probe pets, but the timer is armed by GRUB before `kmain`, so petting during `kmain` *does* extend the deadline without bmctl). That matters: if the codec stalls `probe`, the whole boot stalls while the WDT is being petted, so the reset escape hatch is defeated. Bound the widget iteration count / drop `wdt::pet()` from the dump path.

### S3. `say` / `type` abuse — acceptable *relative to* authenticated peer, but `say` has no length bound

```rust
"say" => {
    console::status(cmd.splitn(2, ' ').nth(1).unwrap_or(""));
```

`type` bounds to 1024 (`TYPED`), `say` does not: `console::status` receives an arbitrary-length slice from the authenticated command. Given the threat model ("an authenticated peer can already do much more"), this is not a new capability — but a 4-digit-NUL/over-long `say` could overflow whatever `status`/`put` does. Verify `console::status` clamps to `W`. If it doesn't, this is a MUST.

### S4. t7 GRUB: `rdmsr 0x10` is **outside** the `if [ "$wdt_ok" = "yes" ]` guard for `nc110_tsc0`

```sh
insmod rdmsr
rdmsr 0x10 -v nc110_tsc0
...
if [ \"\$wdt_ok\" = \"yes\" ]; then
  rdmsr 0x10 -v nc110_tsc1
  if multiboot /baremetal/$KN bmctl grubtsc=\${nc110_tsc0},\${nc110_tsc1}; then
```

If `rdmsr` is missing on the target GRUB build (`insmod rdmsr` fails silently or aborts the entry), or `rdmsr 0x10` faults on a CPU/GRUB combo where MSR 0x10 isn't readable, GRUB behavior on a failed `rdmsr` (it prints an error but **does not abort the menuentry** by default in most builds — `-v` stores whatever). Then `\${nc110_tsc0}` expands to an empty string, and the kernel gets `grubtsc=,` — harmless *in the kernel* (`from_str_radix` fails, the whole `grubtsc` block is skipped). So the netbook still boots. **However**: this is a single `menuentry`; if `insmod rdmsr` ever *does* abort (or if `rdmsr` is a builtin that errors fatally on some GRUB), the entry dies and — per rule (b) — you must ensure a fallback entry exists. The installer's `--set-default`/`saved_entry` logic now matches `t[0-9][0-9]*`:

```sh
E=$(S "grep -o '^menuentry \"nc110-bm-agentos-t[0-9][0-9]*-$2\"' /boot/grub/grub.cfg | tail -1 | cut -d'\"' -f2")
```

This is a **behavior change**: `t[0-9]*` → `t[0-9][0-9]*` now requires **two** digits, so `t6` (single digit) is no longer matched by `--set-default`. If a board is mid-upgrade (grub.cfg has both `t6-…` and `t7-…`), or if the digit-2 assumption is wrong for any future tag, `--set-default` silently picks the wrong entry or none. `grep -o` + `tail -1` picks the *last* match, which is fragile across GRUB's ordering. Confirm the fallback entry (t6) is still present and still the `saved_entry` fallback; if the only reason t6 exists was single-digit matching and it's now excluded, this can leave no valid default after a t7 install failure.

### S5. `phy_reset` return value discarded in the keep-fallback path

```rust
if keep && st & R::LINK_STATUS == 0 {
    kprintln!("nic: no link 1 s after keeping the PHY: resetting it after all");
    self.phy_reset()?;
    st = wait_link(5000);
}
```

The `?` propagates, good. But the *primary* keep path relies on `keep` being read **before** `self.reset()`:

```rust
let keep = unsafe { self.bus.r8(r.phystatus) } & R::LINK_STATUS != 0 && unsafe { !FORCE_PHY_RESET };
self.reset()?;
```

`self.reset()` reinitializes the MAC, and on r8169 the PHY may or may not survive. The 1 s fallback covers the "link was lost" case, and the 5 s re-check covers it, so correctness is preserved — but note the failure mode where `keep` is true (link was up), `reset()` clears link, 1 s elapses, `phy_reset()` is called, and **then** `st` is reported from a 5 s wait. That's fine. The one real gap: `phy_reset` returns `Err` on a 500 ms self-clear timeout, and that propagates out of `init_8101e` → NIC init fails → per the existing code path, no link → chip stopped. That's the correct conservative behavior. No MUST here; the ordering is sound.

## NIT

- `hda.rs` line: `if codecs & 1 == 0 || h.param(0, 0, 0x00) != Some(0x10ec_0269)` — hard-codes codec check *after* the dump loop ran `wdt::pet()` many times; fine but the `!=` against `Some(...)` means `None` (verb timeout) also bails, which is intended.
- `clippy`: `for (i, x) in c.iter_mut().enumerate()` in `console::corner` — fine. The removed `let _ = i;` in `Console::write` is a pure cleanup, no semantic change.
- `nc110-voice.py`: `st[:1] != ["clip"]` and `f[5] == "1"` index by fixed positions of the `aud` status string; any wording change in `format_args!("clip {} bytes {} recording {} peak {} ...")` silently breaks parsing. Fragile but not a kernel bug.
- `tools/nc110-voice.py` writes clips under `proof/voice` only with `--keep`; otherwise `tempfile.mkdtemp()` — good, respects rule (c). But `bm("type", text)` sends transcript back over bmctl — correct channel.
- `hda::probe` sets `pci::write32(b, 0x44, pci::read32(b, 0x44) & !7)` — clearing TCSEL TC bits. This is a `write32` of the *same* register Linux does (`azx_init_pci`), but it's done once at probe, not re-applied; if anything else in the system re-writes TCSEL, LPIB freezes again. Acceptable given priorities.

## Verdict

**5/10.** The two MUST-FIX items are real: the capture ring has no lap/overrun detection (M1) — a long blocking `step` corrupts the clip silently — and `map_uc_4k` mutates a page table it can't prove it owns (M2), which on a machine whose whole premise is "switching PDE attributes used to brick things" is the highest-consequence defect in the diff. The watchdog/GRUB/PHY paths are, on inspection, conservative and mostly correct (S1's tighter claim and S4's t6-matching change are the notable soft spots, not clean breaks). Nothing in the new paths pets the watchdog while bmctl is live except the pre-bmctl `kmain` probe, which is bounded-duration in practice but not in code (S2).

   204	    let v = |nid: u32, verb: u32| h.verb(0, nid, verb);
   205	    for nid in [AFG, ADC, SEL, MIC] {
   206	        let _ = v(nid, 0x705 << 8); // power state D0
   207	    }

   209	    let mic_amp = h.param(0, MIC, 0x0D).unwrap_or(0);
   210	    let mic_gain = ((mic_amp >> 8) & 0x7F).min(2); // boost steps (typically 10 dB each): +20 dB
   211	    let _ = v(MIC, 0x3 << 16 | 0x7000 | mic_gain);
   212	    let _ = v(SEL, 0x701 << 8 | SEL_MIC);
   213	    let sel_amp = h.param(0, SEL, 0x0D).unwrap_or(0);
   214	    let _ = v(SEL, 0x3 << 16 | 0x7000 | SEL_MIC << 8 | (sel_amp & 0x7F));
   215	    let adc_amp = h.param(0, ADC, 0x0D).unwrap_or(0);
   216	    let _ = v(ADC, 0x3 << 16 | 0x7000 | (adc_amp & 0x7F)); // 0 dB (the caps' offset step), unmuted
   217	    let _ = v(ADC, 0x2 << 16 | FMT_48K_STEREO_16 as u32);
   218	    let _ = v(ADC, 0x706 << 8 | (TAG as u32) << 4);
   219	    kprintln!("hda: readback adc fmt {:x?} stream {:x?} pwr {:x?} | sel conn {:x?} pwr {:x?} | mic pinctl {:x?} pwr {:x?} | afg pwr {:x?}",

   226	/// Start a recording of up to `ms` (capped at 30 s). Replaces the previous clip. Err = no capture hardware.
   227	pub fn rec_start(ms: i64) -> Result<u32, &'static str> {
   228	    let Some(h) = (unsafe { DEV }) else { return Err("no capture (cmdline hda, ALC269)") };
   229	    unsafe {
   230	        h.w8(SD, 0); // stop
   231	        h.w8(SD, 1); // SRST
   232	        for _ in 0..1000 {
   233	            if h.r8(SD) & 1 != 0 {
   234	                break;
   235	            }
   236	        }
   237	        h.w8(SD, 0);
   238	        for _ in 0..1000 {
   239	            if h.r8(SD) & 1 == 0 {
   240	                break;
   241	            }
   242	        }
   243	        let base = core::ptr::addr_of!(DMA) as u64;
   244	        let bdl = &mut *core::ptr::addr_of_mut!(BDL);
   245	        for (i, e) in bdl.0.iter_mut().enumerate() {
   246	            let a = base + (i * RING / NBDL) as u64;
   247	            *e = [a as u32, (a >> 32) as u32, (RING / NBDL) as u32, 0];
   248	        }
   249	        let bdla = core::ptr::addr_of!(BDL) as u64;
   250	        h.w8(SD + 3, 0x1C); // clear status
   251	        h.w32(SD + 0x08, RING as u32); // CBL
   252	        h.w16(SD + 0x0C, (NBDL - 1) as u16); // LVI
   253	        h.w16(SD + 0x12, FMT_48K_STEREO_16);
   254	        h.w32(SD + 0x18, bdla as u32);
   255	        h.w32(SD + 0x1C, (bdla >> 32) as u32);
   256	        h.w8(SD + 2, TAG << 4); // stream number
   257	        CLIP_LEN = 0;
   258	        PEAK = 0;
   259	        LAST_POS = 0;
   260	        ACC = (0, 0);
   261	        CLIP_ID += 1;
   262	        OVERRUN = false;
   263	        LAST_POLL = time::now_ms();
   264	        REC_UNTIL = Some(time::now_ms() + ms.clamp(100, 30_000));
   265	        h.w8(SD, 0x02); // RUN
   266	        let id = CLIP_ID;
   267	        kprintln!("hda: recording clip {} for {} ms", id, ms.clamp(100, 30_000));
   268	        Ok(id)
   269	    }
   270	}

   326	/// Drain the DMA ring into the clip (called every pass of the bmctl loop; the ring holds ~340 ms).
   327	pub fn poll(now: i64) {
   328	    unsafe {
   329	        let (Some(h), Some(until)) = (DEV, REC_UNTIL) else { return };
   330	        // The ring holds ~1.4 s; a pass that came back later than 1 s may have been lapped: drop the clip, say so.
   331	        if now - LAST_POLL > 1000 {
   332	            OVERRUN = true;
   333	            CLIP_LEN = 0;
   334	            rec_stop();
   335	            crate::console::corner(None);
   336	            kprintln!("hda: capture overrun ({} ms between polls): clip dropped", now - LAST_POLL);
   337	            return;
   338	        }
   339	        LAST_POLL = now;
   340	        let pos = (h.r32(SD + 0x04) as usize & !3) % RING; // LPIB, whole stereo frames
   341	        let ring = &*core::ptr::addr_of!(DMA);
   342	        let clip = &mut *core::ptr::addr_of_mut!(CLIP);
   343	        while LAST_POS != pos && CLIP_LEN < CLIP_MAX {
   344	            let f = &ring.0[LAST_POS..LAST_POS + 4];
   345	            let l = i16::from_le_bytes([f[0], f[1]]) as i32;
   346	            let r = i16::from_le_bytes([f[2], f[3]]) as i32;
   347	            ACC.0 += (l + r) / 2;
   348	            ACC.1 += 1;
   349	            if ACC.1 == 3 {
   350	                let s = (ACC.0 / 3) as i16;
   351	                clip[CLIP_LEN] = s;
   352	                CLIP_LEN += 1;
   353	                PEAK = PEAK.max(s.saturating_abs());
   354	                ACC = (0, 0);
   355	            }
   356	            LAST_POS = (LAST_POS + 4) % RING;
   357	        }
   358	        if now >= until || CLIP_LEN >= CLIP_MAX {
   359	            rec_stop();
   360	            crate::console::corner(None);
   361	        }
   362	    }
   363	}

    41	/// Native 1024x600 (cmdline `gmafb`): keep the VBIOS's LVDS timing on pipe B (already the panel's 1024x600), but feed
    42	/// it from display plane B at 32 bpp out of the graphics aperture instead of the VGA plane the panel fitter stretches
    43	/// (640x400 -> 1024x600). Pineview is gen3: the plane base is DSPBADDR (a GTT offset; 0 = aperture start, the memory
    44	/// GRUB's VESA modes also used). Only proceeds if pipe B drives the LVDS at 1024x600; a reboot restores the VBIOS mode.
    45	pub fn native_fb() -> Option<crate::console::Fb> {
    46	    let b = pci::find(0x8086, 0xA011).or_else(|| pci::find(0x8086, 0xA001))?;
    47	    let bar = pci::read32(b, 0x10) as u64 & !0xF;
    48	    let gmadr = pci::read32(b, 0x18) as u64 & !0xF;
    49	    for off in [0x61000u32, 0x61180, 0x61200, 0x70000, 0x71000, 0x71400] { // 0x61000 page also holds 0x61230
    50	        if !nic::map_uc_4k(bar + off as u64) {
    51	            return None;
    52	        }
    53	    }
    54	    let (htot, vtot, lvds) = (rd(bar, 0x61000), rd(bar, 0x6100c), rd(bar, 0x61180));
    55	    let (w, h) = ((htot & 0xFFF) + 1, (vtot & 0xFFF) + 1);
    56	    if lvds & (1 << 31) == 0 || lvds & (1 << 30) == 0 || (w, h) != (1024, 600) {
    57	        kprintln!("gma: native fb refused: LVDS {:#x}, pipe B active {}x{}", lvds, w, h);
    58	        return None;
    59	    }
    60	    pci::write32(b, 4, pci::read32(b, 4) & 0xFFFF | 0x6); // memory + bus master (display fetch)
    61	    // Uncached BEFORE the clear (review MF-D): clearing through the boot's write-back mapping could leave dirty lines that
    62	    // a later eviction writes over pixels drawn uncached.
    63	    if !nic::map_fb(gmadr, 4096 * 600) {
    64	        kprintln!("gma: aperture {:#x} could not be mapped uncached: staying on VGA text", gmadr);
    65	        return None;
    66	    }
    67	    // Clear the first screen of the aperture before the plane shows it.
    68	    for i in 0..(1024 * 600) as u64 {
    69	        unsafe { core::ptr::write_volatile((gmadr + i * 4) as *mut u32, 0) };
    70	    }
    71	    // Linux's i9xx order: planes off, pipe off (wait for it), then panel fitter and source size, pipe on, plane on.
    72	    // Attempt 1 changed PIPEBSRC with the pipe running: the fitter ignored the disable and kept its 640x400 ratios,
    73	    // and PIPEBSTAT showed a FIFO underrun (black screen).
    74	    wr(bar, 0x71400, rd(bar, 0x71400) | (1 << 31)); // VGACNTRL: VGA plane off
    75	    wr(bar, 0x71180, rd(bar, 0x71180) & !(1 << 31)); // plane B off
    76	    wr(bar, 0x71184, 0);
    77	    // gen3 PIPECONF has no pipe-state bit (it read 0x80000000 throughout attempt 2): wait two frames instead.
    78	    let pf0 = (rd(bar, 0x61230), rd(bar, 0x61234), rd(bar, 0x61238));
    79	    wr(bar, 0x71008, rd(bar, 0x71008) & !(1 << 31)); // PIPEBCONF: pipe off
    80	    crate::wdt::delay_ms(40);
    81	    wr(bar, 0x61230, 0); // PFIT_CONTROL (0x61230 on gen3/4; 0x61200 is PP_STATUS): fitter off, source = native
    82	    wr(bar, 0x6101c, (1023 << 16) | 599); // PIPEBSRC
    83	    wr(bar, 0x71008, rd(bar, 0x71008) | (1 << 31)); // pipe on
    84	    crate::wdt::delay_ms(40);
    85	    kprintln!("gma: PFIT ctl/pgm/auto {:x?} -> ctl {:#x}", pf0, rd(bar, 0x61230));
    86	    wr(bar, 0x71188, 4096); // DSPBSTRIDE
    87	    wr(bar, 0x71190, (599 << 16) | 1023); // DSPBSIZE
    88	    wr(bar, 0x7118c, 0); // DSPBPOS
    89	    // DSPBCNTR: on, 32 bpp xRGB, pipe B. Gamma (bit 30) stays OFF: the VBIOS's palette is the 8-bit VGA one, and through
    90	    // it the 32 bpp colours came out wrong (cyan white, grey chips white; camera shot proof/cam-native-gamma-on.jpg).
    91	    wr(bar, 0x71180, (1 << 31) | (6 << 26) | (1 << 24));
    92	    wr(bar, 0x71184, 0); // DSPBADDR: aperture offset 0 (writing it latches the plane registers)
    93	    wr(bar, 0x71024, rd(bar, 0x71024) | (1 << 31)); // PIPEBSTAT: clear the underrun flag (RW1C) so `gma` shows new ones
    94	    crate::wdt::delay_ms(50);

    97	        restore_vga_regs(bar);
    98	        return None;
    99	    }

   101	        rd(bar, 0x6101c), rd(bar, 0x61230), rd(bar, 0x71400));
   102	    Some(crate::console::Fb { addr: gmadr, pitch: 4096, w: 1024, h: 600, bytes: 4, rgb: [(16, 8), (8, 8), (0, 8)] })
   103	}

    77	// VGA palette (attribute colours 0..15) as RGB.
    78	const PAL: [u32; 16] = [0x000000, 0x0000AA, 0x00AA00, 0x00AAAA, 0xAA0000, 0xAA00AA, 0xAA5500, 0xAAAAAA, 0x555555, 0x5555FF,
    79	    0x55FF55, 0x55FFFF, 0xFF5555, 0xFF55FF, 0xFFFF55, 0xFFFFFF];

    81	fn pixel(fb: &Fb, rgb: u32) -> u32 {
    82	    let ch = |v: u32, (pos, size): (u8, u8)| (v >> (8 - size.min(8))) << (pos & 31);
    83	    ch(rgb >> 16 & 0xFF, fb.rgb[0]) | ch(rgb >> 8 & 0xFF, fb.rgb[1]) | ch(rgb & 0xFF, fb.rgb[2])
    84	}

    86	fn draw(i: usize, v: u16, underline: bool) {
    87	    let Some((fb, x0, y0)) = (unsafe { *core::ptr::addr_of!(FB) }) else { return };
    88	    let attr = (v >> 8) as usize;
    89	    let (fg, bg) = (pixel(&fb, PAL[attr & 0xF]), pixel(&fb, PAL[attr >> 4 & 0xF]));
    90	    let f = font();
    91	    let g = f.glyph((v & 0xFF) as u8);
    92	    let (cx, cy) = (x0 + (i % cols()) as u32 * f.w as u32, y0 + (i / cols()) as u32 * f.h as u32);
    93	    // The side margins (1024 - 960 = 2 x 32 px on the NC110) take the background of the edge cell next to them, so
    94	    // the footer bar and coloured terminal rows reach the panel edges.
    95	    let margin = match i % cols() {
    96	        0 => Some((0, x0)),
    97	        c if c == cols() - 1 => Some((cx + f.w as u32, fb.w)),
    98	        _ => None,
    99	    };
   100	    if let Some((mx0, mx1)) = margin {
   101	        for y in 0..f.h as u32 {
   102	            let line = fb.addr + (cy + y) as u64 * fb.pitch as u64;
   103	            for x in mx0..mx1 {
   104	                let a = line + (x * fb.bytes) as u64;
   105	                unsafe {
   106	                    match fb.bytes {
   107	                        4 => core::ptr::write_volatile(a as *mut u32, bg),
   108	                        3 => {
   109	                            core::ptr::write_volatile(a as *mut u16, bg as u16);
   110	                            core::ptr::write_volatile((a + 2) as *mut u8, (bg >> 16) as u8);
   111	                        }
   112	                        _ => core::ptr::write_volatile(a as *mut u16, bg as u16),
   113	                    }
   114	                }
   115	            }
   116	        }
   117	    }
   118	    for (y, &bits) in g.iter().enumerate() {
   119	        let bits = if underline && y + 3 >= f.h && y + 1 < f.h { (1 << f.w) - 1 } else { bits };
   120	        let line = fb.addr + (cy + y as u32) as u64 * fb.pitch as u64 + cx as u64 * fb.bytes as u64;
   121	        for x in 0..f.w {
   122	            let p = if bits & (1 << (f.w - 1 - x)) != 0 { fg } else { bg };
   123	            let a = line + (x as u32 * fb.bytes) as u64;
   124	            unsafe {
   125	                match fb.bytes {
   126	                    4 => core::ptr::write_volatile(a as *mut u32, p),
   127	                    3 => {
   128	                        core::ptr::write_volatile(a as *mut u16, p as u16);
   129	                        core::ptr::write_volatile((a + 2) as *mut u8, (p >> 16) as u8);
   130	                    }
   131	                    _ => core::ptr::write_volatile(a as *mut u16, p as u16),
   132	                }
   133	            }
   134	        }
   135	    }
   136	}

   138	/// Set one cell (VGA attribute << 8 | CP437 char). Only a changed cell is redrawn.
   139	pub fn cell(i: usize, v: u16) {
   140	    unsafe {
   141	        let sh = &mut *core::ptr::addr_of_mut!(SHADOW);

   143	            return;

   152	    }

   159	/// Text cursor at cell `pos` (None hides it): the VGA hardware cursor, or an underline on the framebuffer.
   160	pub fn cursor(pos: Option<usize>) {
   161	    unsafe {
   162	        if (*core::ptr::addr_of!(FB)).is_some() {
   163	            let old = CURSOR;
   164	            CURSOR = pos;
   165	            if old != pos {
   166	                if let Some(o) = old {
   167	                    draw(o, shown(o, cell_get(o)), false);
   168	                }
   169	                if let Some(p) = pos {
   170	                    draw(p, shown(p, cell_get(p)), true);
   171	                }
   172	            }
   173	            return;
   174	        }
   175	        match pos {
   176	            None => {
   177	                outb(0x3D4, 0x0A);
   178	                outb(0x3D5, 0x20); // bit 5 hides the cursor
   179	            }
   180	            Some(p) => {
   181	                outb(0x3D4, 0x0A);
   182	                outb(0x3D5, 13); // scanlines 13..14
   183	                outb(0x3D4, 0x0B);
   184	                outb(0x3D5, 14);
   185	                outb(0x3D4, 0x0F);
   186	                outb(0x3D5, p as u8);
   187	                outb(0x3D4, 0x0E);
   188	                outb(0x3D5, (p >> 8) as u8);
   189	            }
   190	        }
   191	    }
   192	}

   194	/// Switch the screen to a multiboot linear framebuffer (needs >= 960x600 and 16/24/32 bpp): clear it and redraw every
   195	/// cell from the shadow. False = not usable (the caller keeps VGA text, which a graphics mode will not show).
   196	pub fn use_framebuffer(fb: Fb) -> bool {
   197	    let f = font();
   198	    if fb.w < 80 * f.w as u32 || fb.h < 25 * f.h as u32 || !(2..=4).contains(&fb.bytes) || fb.pitch < fb.w * fb.bytes {
   199	        return false;
   200	    }
   201	    if !crate::nic::map_fb(fb.addr, fb.pitch as u64 * fb.h as u64) {
   202	        return false;
   203	    }
   204	    unsafe {
   205	        for y in 0..fb.h as u64 {
   206	            core::ptr::write_bytes((fb.addr + y * fb.pitch as u64) as *mut u8, 0, (fb.w * fb.bytes) as usize);
   207	        }
   208	        FB = Some((fb, 0, 0));
   209	    }
   210	    set_font(f);
   211	    true
   212	}

   214	/// Framebuffer only: switch the cell font (the grid becomes the panel divided by the cell, up to 170x50) and repaint
   215	/// from the shadow. The callers redraw their screen (splash / terminal) at the new size.
   216	pub fn set_font(f: &'static crate::font::Font) {
   217	    unsafe {
   218	        let Some((fb, _, _)) = *core::ptr::addr_of!(FB) else { return };
   219	        let (c, r) = ((fb.w as usize / f.w).min(MAXW), (fb.h as usize / f.h).min(MAXH));
   220	        FONT = f;
   221	        (COLS, ROWS) = (c, r);
   222	        FB = Some((fb, (fb.w - (c * f.w) as u32) / 2, (fb.h - (r * f.h) as u32) / 2));
   223	        CURSOR = None;
   224	        POINTER = None;
   225	        for y in 0..fb.h as u64 {
   226	            core::ptr::write_bytes((fb.addr + y * fb.pitch as u64) as *mut u8, 0, (fb.w * fb.bytes) as usize);
   227	        }
   228	        (*core::ptr::addr_of_mut!(SHADOW)).fill(0);
   229	    }
   230	}

   356	/// Key hints under the status line: each key as a light chip, then its label.

   360	    }
   361	    let row = status_row() + 4;

   444	fn serial_putc(b: u8) {
   445	    unsafe {
   446	        // Bounded: a wedged or absent UART must never keep a failure path from reaching its 0xCF9 reset.
   447	        for _ in 0..100_000 {
   448	            if inb(COM1 + 5) & 0x20 != 0 {
   449	                outb(COM1, b);
   450	                return;
   451	            }
   452	        }
   453	    }
   454	}

   456	fn vga_putc(b: u8) {
   457	    unsafe {
   458	        if b == b'\n' {
   459	            COL = 0;
   460	            ROW += 1;
   461	        } else {
   462	            cell(ROW * cols() + COL, ATTR | b as u16);
   463	            COL += 1;
   464	            if COL == cols() {
   465	                COL = 0;
   466	                ROW += 1;
   467	            }
   468	        }
   469	        if ROW == rows() {
   470	            for i in 0..cols() * (rows() - 1) {
   471	                cell(i, cell_get(i + cols()));
   472	            }
   473	            for i in 0..cols() {
   474	                cell((rows() - 1) * cols() + i, ATTR | b' ' as u16);
   475	            }
   476	            ROW = rows() - 1;
   477	        }
   478	    }
   479	}

//! Intel High Definition Audio: internal-mic capture for push-to-talk. Finds the controller (PCI class 04:03), resets it,
//! talks to the codec over the Immediate Command interface (ICOI/IRII/ICIS: no CORB/RIRB DMA). `hdadump` logs every
//! widget (type, pin default configuration). Capture path (NC110: Realtek ALC269, proof/nc110-hda-discovery.log):
//! internal mic pin 0x19 -> selector 0x22 (input 1) -> ADC 0x09, 48 kHz stereo 16-bit into a 64 KiB DMA ring on input
//! stream 0, decimated here to 16 kHz mono 16-bit into a RAM clip (max 30 s). The clip leaves the box only over bmctl
//! (`rec`, `aud`: authenticated and encrypted). Enabled by cmdline `hda` (the default boot never touches it).
use crate::{kprintln, nic, pci, time, wdt};
use core::ptr::{read_volatile, write_volatile};

const GCTL: u64 = 0x08;
const STATESTS: u64 = 0x0E;
const ICOI: u64 = 0x60;
const IRII: u64 = 0x64;
const ICIS: u64 = 0x68;

#[derive(Clone, Copy)]
struct Hda(u64);

impl Hda {
    fn r8(&self, o: u64) -> u8 {
        unsafe { read_volatile((self.0 + o) as *const u8) }
    }
    fn w8(&self, o: u64, v: u8) {
        unsafe { write_volatile((self.0 + o) as *mut u8, v) }
    }
    fn r16(&self, o: u64) -> u16 {
        unsafe { read_volatile((self.0 + o) as *const u16) }
    }
    fn r32(&self, o: u64) -> u32 {
        unsafe { read_volatile((self.0 + o) as *const u32) }
    }
    fn w16(&self, o: u64, v: u16) {
        unsafe { write_volatile((self.0 + o) as *mut u16, v) }
    }
    fn w32(&self, o: u64, v: u32) {
        unsafe { write_volatile((self.0 + o) as *mut u32, v) }
    }

    /// One verb over the immediate interface: wait not busy, write, set ICB, wait for IRV. Bounded (~10 ms each).
    fn verb(&self, cad: u32, nid: u32, verb: u32) -> Option<u32> {
        for _ in 0..1000 {
            if self.r16(ICIS) & 1 == 0 {
                break;
            }
            wdt::delay_ms(0);
        }
        self.w16(ICIS, 2); // clear IRV (RW1C)
        self.w32(ICOI, cad << 28 | nid << 20 | verb);
        self.w16(ICIS, 1); // ICB: send
        for _ in 0..1000 {
            let s = self.r16(ICIS);
            if s & 1 == 0 && s & 2 != 0 {
                return Some(self.r32(IRII));
            }
            for _ in 0..100 {
                core::hint::spin_loop();
            }
        }
        None
    }

    fn param(&self, cad: u32, nid: u32, p: u32) -> Option<u32> {
        self.verb(cad, nid, 0xF00 << 8 | p)
    }
}

pub fn probe(dump: bool) {

        }

        return;

        return;

        return;

                        }

                } else {

                }
            }
        }
    }    if codecs & 1 == 0 || h.param(0, 0, 0x00) != Some(0x10ec_0269) {

}

   242	        return Err("setup header too short for the fields this loader uses");
   243	    }
   244	    let (dst, init_size, pref) = (r32(0x214), r32(0x260), r32(0x258) | r32(0x25c) << 32);
   245	    let (kalign, reloc, cmax) = (r32(0x230), img[0x234] != 0, r32(0x238));
   246	    let len = st.size.checked_sub(off).ok_or("image shorter than its setup")?;
   247	    if dst != 0x10_0000 || dst + len > STAGE || !mb::ram_contains(dst, len) {
   248	        return Err("protected-mode code must load at 1 MiB, below staging, in RAM");
   249	    }
   250	    // Where the kernel decompresses and runs (boot.rst): pref_address if not relocatable; if relocatable, the load
   251	    // address aligned up to kernel_alignment, or pref_address. Both candidate intervals must be RAM below 4 GiB.
   252	    if init_size == 0 || (reloc && !kalign.is_power_of_two()) {
   253	        return Err("bad init_size / kernel_alignment");
   254	    }
   255	    // relocatable: align_up(max(load address, pref_address), kernel_alignment); fixed: pref_address
   256	    let runat = if reloc {
   257	        dst.max(pref).checked_add(kalign - 1).ok_or("alignment overflow")? & !(kalign - 1)
   258	    } else {
   259	        pref
   260	    };
   261	    for base in [runat] {
   262	        match base.checked_add(init_size) {
   263	            Some(end) if end <= 0x1_0000_0000 && mb::ram_contains(base, init_size) => {}
   264	            _ => return Err("kernel's runtime range (init_size at pref/aligned address) not RAM below 4 GiB"),
   265	        }
   266	    }
   267	    let run = runat;
   268	    if cmdline.len() > 2047 || cmdline.len() as u64 > cmax || !mb::ram_contains(BP, 0x2000) {
   269	        return Err("cmdline longer than 2047 / the kernel's cmdline_size, or boot_params pages not RAM");
   270	    }
   271	    let tl = (core::ptr::addr_of!(tramp_end) as u64) - (core::ptr::addr_of!(tramp_start) as u64);
   272	    if tl > PARAMS - TRAMP || !mb::ram_contains(TRAMP, LOW_END - TRAMP) {
   273	        return Err("low pages 0x8000-0xA000 not usable");
   274	    }
   275	    unsafe {
   276	        if ORIG_MMAP_TOO_BIG || ORIG_MMAP_LEN == 0 {
   277	            return Err("no usable GRUB memory map snapshot for the E820 table");
   278	        }
   279	        core::ptr::write_bytes(BP as *mut u8, 0, 0x2000);
   280	        core::ptr::write_bytes(TRAMP as *mut u8, 0, (LOW_END - TRAMP) as usize);
   281	        core::ptr::copy_nonoverlapping(core::ptr::addr_of!(tramp_start), TRAMP as *mut u8, tl as usize);
   282	        let hend = (0x202 + img[0x201] as usize).min(0x290);
   283	        core::ptr::copy_nonoverlapping(img.as_ptr().add(0x1f1), (BP + 0x1f1) as *mut u8, hend - 0x1f1);
   284	        for o in [0x218u64, 0x21c, 0x250, 0x254] {
   285	            core::ptr::write_volatile((BP + o) as *mut u32, 0); // no initrd, no setup_data chain
   286	        }
   287	        core::ptr::write_volatile((BP + 0x210) as *mut u8, 0xFF); // type_of_loader: undefined
   288	        core::ptr::write_volatile((BP + 0x228) as *mut u32, BP_CMD as u32); // cmd_line_ptr
   289	        core::ptr::copy_nonoverlapping(cmdline.as_ptr(), BP_CMD as *mut u8, cmdline.len());
   290	        // E820 from the multiboot map: entries {size u32, base u64, len u64, type u32}, stride size + 4
   291	        let mm = &*core::ptr::addr_of!(ORIG_MMAP);
   292	        let (mut p, mut n) = (0usize, 0u64);
   293	        while p < ORIG_MMAP_LEN {
   294	            if p + 4 > ORIG_MMAP_LEN {
   295	                return Err("GRUB memory map ends inside a record header");
   296	            }
   297	            let sz = u32::from_le_bytes(mm[p..p + 4].try_into().unwrap()) as usize;
   298	            if sz < 20 || p + 4 + sz > ORIG_MMAP_LEN || n >= 128 {
   299	                return Err("GRUB memory map record malformed (size < 20, overrun) or > 128 records");
   300	            }
   301	            let e = BP + 0x2d0 + 20 * n;
   302	            core::ptr::copy_nonoverlapping(mm.as_ptr().add(p + 4), e as *mut u8, 20);
   303	            n += 1;
   304	            p += sz + 4;
   305	        }
   306	        core::ptr::write_volatile((BP + 0x1e8) as *mut u8, n as u8);
   307	    }
   308	    kprintln!("loader: Linux ready: bzImage proto {:#x}, {} B pm code -> {:#x}, init_size {:#x} at {:#x}, cmdline '{}'", ver, len, dst, init_size, run, cmdline);
   309	    Ok(Plan { params: [STAGE + off, dst, len, 0, dst, BP, 1] })
   310	}

   312	/// Point of no return: NIC quiesced (reset completed), trampoline entered. The TCO stays armed across the hop.
   313	/// If the NIC reset does not complete, its DMA may still target memory the new image would overwrite: hard reset
   314	/// instead of jumping (GRUB default, the agent OS, then the crash-loop escape).
   315	pub fn jump(p: &Plan, nic: &Rtl) -> ! {
   316	    if let Err(e) = nic.quiesce() {
   317	        kprintln!("loader: NIC quiesce failed ({}): NOT jumping, hard reset", e);
   318	        crate::wdt::hard_reset();
   319	    }
   320	    unsafe {
   321	        for (i, v) in p.params.iter().enumerate() {
   322	            core::ptr::write_volatile((PARAMS + 8 * i as u64) as *mut u64, *v);
   323	        }
   324	        crate::wdt::pet();
   325	        let f: extern "sysv64" fn(u64) -> ! = core::mem::transmute(TRAMP as usize);
   326	        f(PARAMS)
   327	    }

    79	/// Drain firmware leftovers, then read the i8042 command byte (cmd 0x20) and require translation (bit 6):

    82	fn cmd(c: u8) -> bool {

    84	        for _ in 0..1_000_000 {

    86	                crate::port::outb(STATUS, c);
    87	                return true;
    88	            }

   155	/// Send a byte to the AUX device (touchpad in PS/2 mouse mode) and wait for its ACK (0xFA).
   156	fn aux(b: u8) -> bool {
   157	    if !cmd(0xD4) {
   158	        return false;
   159	    }
   160	    unsafe {
   161	        for _ in 0..1_000_000 {
   162	            if inb(STATUS) & 2 == 0 {
   163	                outb(DATA, b);
   164	                return read_byte(true) == Some(0xFA);
   165	            }
   166	        }
   167	    }
   168	    false

   171	/// Once per boot: AUX port on with its clock enabled and interrupts off (we poll), defaults, IntelliMouse wheel probe
   172	/// (sample rate 200, 100, 80 then ID 3 = 4-byte packets), reporting on. Every step is bounded; failure leaves no mouse.
   173	fn mouse_init(cfg: u8) {
   174	    if unsafe { MOUSE } {
   175	        return;
   176	    }
   177	    cmd(0xA8); // enable AUX interface
   178	    if cmd(0x60) {
   179	        unsafe {
   180	            for _ in 0..1_000_000 {
   181	                if inb(STATUS) & 2 == 0 {
   182	                    // keyboard + AUX clocks on (cfg was read while init() had the keyboard paused: bit 4 set), AUX IRQ off
   183	                    outb(DATA, cfg & !0x10 & !0x20 & !0x02);
   184	                    break;
   185	                }
   186	            }
   187	        }
   188	    }
   189	    drain();
   190	    // Full reset first: a pad Linux's elantech driver switched to absolute mode stays there across a warm reset, and
   191	    // 0xF6 does not undo it (measured: 6-byte Elantech packets, proof/nc110-touchpad-raw-elantech.log). 0xFF does: ACK,
   192	    // then the self-test result 0xAA and the ID 0x00 within ~500 ms.
   193	    let mut bat = None;
   194	    if aux(0xFF) {
   195	        let t = crate::time::now_ms();
   196	        while bat.is_none() && crate::time::now_ms() - t < 1500 {
   197	            bat = read_byte(true);
   198	        }
   199	        let _ = read_byte(true); // device ID after the self-test
   200	    }
   201	    let ok = aux(0xF6) && aux(0xF3) && aux(200) && aux(0xF3) && aux(100) && aux(0xF3) && aux(80) && aux(0xF2);
   202	    let id = if ok { read_byte(true) } else { None };
   203	    let on = ok && aux(0xF4);
   204	    unsafe {
   205	        WHEEL = id == Some(3);
   206	        MOUSE = on;
   207	    }
   208	    crate::kprintln!("kbd: touchpad/mouse {} (reset self-test {:x?}, id {:?}{})", if on { "on" } else { "NOT answering" }, bat, id,
   209	        if id == Some(3) { ", wheel" } else { "" });
   210	}

   228	fn aux_byte(b: u8) {
   229	    unsafe {
   230	        (*core::ptr::addr_of_mut!(RAW))[NRAW % 48] = b;
   231	        NRAW += 1;
   232	        // Resync like Linux psmouse: the bytes of one packet arrive back to back, so a gap means a new packet.
   233	        let now = crate::time::now_ms();
   234	        if NPKT > 0 && now - LAST_AUX > 30 {
   235	            NPKT = 0;
   236	        }
   237	        LAST_AUX = now;
   238	        if NPKT == 0 && (b & 0x08 == 0 || b & 0xC0 != 0) {
   239	            return; // not a plausible byte 0: bit 3 always set, X/Y overflow (bits 6/7) treated as noise
   240	        }
   241	        PKT[NPKT] = b;
   242	        NPKT += 1;
   243	        if NPKT < if WHEEL { 4 } else { 3 } {
   244	            return;
   245	        }
   246	        NPKT = 0;
   247	        let b0 = PKT[0];
   248	        let (dx, dy) = if b0 & 0xC0 == 0 {
   249	            (PKT[1] as i32 - ((b0 as i32) << 4 & 0x100), PKT[2] as i32 - ((b0 as i32) << 3 & 0x100))
   250	        } else {
   251	            (0, 0) // overflow: drop the motion, keep the buttons
   252	        };
   253	        let w = if WHEEL { ((PKT[3] << 4) as i8 >> 4) as i32 } else { 0 };
   254	        let q = &mut *core::ptr::addr_of_mut!(MQ);
   255	        if MQN > 0 && q[MQN - 1].3 == b0 & 7 && w == 0 && q[MQN - 1].2 == 0 {
   256	            q[MQN - 1].0 += dx; // same buttons, plain motion: coalesce
   257	            q[MQN - 1].1 += dy;
   258	        } else if MQN < q.len() {
   259	            q[MQN] = (dx, dy, w, b0 & 7);
   260	            MQN += 1;
   261	        }
   262	    }
   263	}

//! VGA text terminal (80x25 at 0xB8000), the xterm subset that ncurses uses with TERM=xterm (htop, vi):
//! CR LF BS TAB BEL SO SI, deferred autowrap (DECAWM), scroll region (CSI r) with LF/IND/RI/S/T/L/M inside it,
//! cursor CSI A B C D E F G ` d e a H f Z, erase J K X with the current background (bce), P @ (and IRM 4h),
//! REP (CSI b), SGR 0/1/2/22/7/27/30-37/39/40-47/49/90-97/100-107 (+38/48;5;n) -> VGA attributes (16 fg and,
//! with the blink bit turned off by `init`, 16 bg colours),
//! ESC 7/8 + CSI s/u + ?1048, alternate screen ?47/?1047/?1049, ?25 cursor, ?1 DECCKM (read by kbd),
//! DEC line drawing (ESC ( 0 / ESC ) 0 + SO/SI) -> CP437 box characters, DECSTR (CSI ! p), ESC c.
//! OSC/DCS/APC/PM/SOS strings are swallowed. UTF-8 is decoded: CP437 glyph where one exists, else '?';
//! East Asian wide characters take 2 cells ("??"), combining marks take none. Replies (DSR 5n/6n, DA1 CSI c,
//! DA2 CSI > c) queue in `take_reply` for the caller to send back over the channel.
//! The grid lives in RAM (`Term`); `flush` copies it to VGA memory and moves the hardware cursor once per batch.
//! Host tests: `sh tools/test-term.sh`.

## MUST-FIX

### M1. `hda::poll` is called **once per `Ctl::step`**, but `step` also `delay_ms`-blocks and the ring only holds ~340 ms → guaranteed overrun + permanent desync

`hda::poll(t)` runs at the top of `step`. But `poll` only advances `LAST_POS` up to `pos` once — and `step` is not called on a fixed cadence (it has an `idle_ms` deadline, footer deadline, and commands that take time). More critically, the drain loop:

```rust
let pos = (h.r32(SD + 0x04) as usize & !3) % RING;
while LAST_POS != pos && CLIP_LEN < CLIP_MAX {
    ...
    LAST_POS = (LAST_POS + 4) % RING;
}
```

has **no overrun detection**. The hardware LPIB wraps the 64 KiB ring. If more than `RING` bytes are produced between two `poll` calls (i.e. any stall > ~340 ms: a `syn`/`lcom` command, the `say` path, a long authenticated command reply, or simply `step` being called late), the NIC/HDA has lapped the reader. `LAST_POS != pos` is then true, the loop copies *stale/overwritten* ring bytes and, on the next poll, `pos` may already be ahead again — the reader silently trails forever and records garbage interleaved with real audio, with no error surfaced. The header comment asserts "the ring holds ~340 ms" as if that bounds the gap, but nothing enforces that `poll` runs faster than that. Contrast with the watchdog discipline elsewhere in this kernel (pet-on-progress): here the capture path has no equivalent guard.

Concrete failing scenario: pull-to-talk on, user types `rec`/`lcom` or the Mac issues `aud`, `step` blocks in the encrypted reply; >340 ms elapse; `poll` laps; the clip is corrupted and `PEAK`/`clip_bytes` still report success.

Fix: track producer/consumer with the half/full-ring semantics HDA already provides (`SD_STS` BCIS/FIFO error bits, or a `CBL`-based write position), detect `pos` crossing `LAST_POS` more than the ring, drop the clip, and surface it.

### M2. `map_uc_4k` reuses an already-split PDE it does not own, and *only* for `UC_USED` bookkeeping — the boot page tables case is real

```rust

    &mut *((old & !0xFFF) as *mut Pt) // already split: one of ours

    ...

    ...
```

The comment says "already split: one of ours", but the code cannot verify that. A boot-page-table (or any firmware/GRUB-created) PDE with `PS=0` pointing at a page table that is **not one of our `UC_PT` slots** is indistinguishable from a prior `map_uc_4k` call. In that case:

- the code indexes into a foreign table and sets `PCD|PWT` on a PTE that belongs to something else (e.g. MMIO that must stay cached, or a DMA buffer), and
- it *overwrites the PDE* with `(pt | 0x3)` where `pt` is the foreign table address — dropping the original PDE flags (US, PWT, PCD, and especially the US bit) to a bare `present|rw`.

More importantly, `NUM`/`membar` case: two different `map_uc_4k` calls whose 2 MiB regions collide (e.g. HD Audio BAR and NIC register window on the same 2 MiB PDE) share a table, which is the intended design, but the **`UC_USED` counter is incremented on the `else` branch even though the collision branch never decrements or reuses** — fine — the real bug is the unverifiable `PS==0` assumption.

Minimal correct fix: tag our tables (reserve a known array, or store an ownership page/sentinel), and if `old & 1` (present) and `PS==0` and the table isn't ours, **bail (`return false`) rather than mutate** — the early `map_uc_4k(bar)` in `hda::probe` returning `false` is already handled gracefully.

/// (base, is_64bit) of the first MEMORY BAR of a type-0 function (mirrors r8169's "first MMIO region",
/// r8169_main.c:5408). Read-only: no BAR sizing writes.
pub fn first_mem_bar(b: Bdf) -> Option<(u64, bool)> {
    let mut i = 0u8;
    while i < 6 {
        let off = 0x10 + 4 * i;
        let lo = read32(b, off);
        if lo != 0 && lo & 1 == 0 { // 0 = unimplemented slot (RTL8102E BAR1), not a memory BAR at 0
            let ty = (lo >> 1) & 3;
            let base = (lo & !0xF) as u64;
            if ty == 2 {
                if i == 5 {
                    return None;
                }
                let hi = read32(b, off + 4) as u64;
                return Some((base | hi << 32, true));
            }
            return Some((base, false));
        }
        i += 1;
    }
    None
}

Most of the control-loop work is sound, but I found **two MUST-FIX issues**. This is a source review; I did not exercise the hardware. The existing terminal tests also fail to compile.

**MUST-FIX**

1. **HDA DMA survives chain-loading and can overwrite the incoming kernel.**  
   [hda.rs:243](~/nc110-baremetal/src/hda.rs:243) programs DMA descriptors pointing into the current kernel’s static storage and starts capture at line 265. [loader.rs:315](~/nc110-baremetal/src/loader.rs:315) quiesces only the NIC before overwriting the kernel.

   **Scenario:** start a 30-second recording, then commit a staged kernel while recording remains active. HDA continues writing to the old ring addresses while the trampoline copies the new image and clears BSS. Those addresses—and the descriptor list itself—can now contain new kernel state. Loading with `nohda` makes this especially clear: the destination never resets that controller.

   Stop HDA, verify it has stopped, and disable its bus mastering before entering either chain-load path. Reset instead if quiescence fails. TCO recovery is a fallback, not protection against DMA corruption during recovery.

2. **`hdadump` exports raw room-audio samples through the plaintext log.**  
   [hda.rs:383](~/nc110-baremetal/src/hda.rs:383) prints `dma[0..8]`, including microphone samples after capture has run. `kprintln!` sends these to COM1 and the captured log. [udplog.rs:40](~/nc110-baremetal/src/udplog.rs:40) broadcasts that log without encryption.

   **Scenario:** record, issue `hdadump` before the 8-KiB log fills, then chain-load or reach the idle-reset path. The subsequent log dump broadcasts those samples on UDP 5514. Authenticating the command does not authenticate or encrypt its logging side effect. Eight bytes still violate rule (c).

   Remove sample contents from general diagnostics; return any sample inspection exclusively through the encrypted bmctl response.

**SHOULD**

- **Legacy mouse reports break beyond column 95.** At [ssh.rs:628](~/nc110-baremetal/src/ssh.rs:628), `s.push(v as char)` UTF-8-encodes coordinates. With zero-based column 95, the required raw byte `0x80` becomes `0xC2 0x80`. This affects the 128- and 170-column grids when tracking is enabled without SGR mode. Build legacy reports in a byte buffer.

- **Restore terminal-test coverage before trusting the grid conversion.** [term_test.rs:7](~/nc110-baremetal/tools/term_test.rs:7) imports removed `term::H` and `term::W`. Compiling the existing harness produced `E0432`; no tests ran. Update it and exercise scrolling, erasing, saved cursors and alternate screens at all three framebuffer sizes.

- **The recording indicator can disappear while capture continues.** [console.rs:383](~/nc110-baremetal/src/console.rs:383) paints `REC` directly into console cells. The next SSH terminal flush overwrites those cells from terminal state; changing fonts or returning home also clears the marker. Render it as an overlay derived from recording state.

- **Temporary audio survives processing failures.** [nc110-voice.py:51](~/nc110-baremetal/tools/nc110-voice.py:51) creates temporary storage, but deletion occurs only after successful transcription and response handling. An exception or timeout after WAV creation leaves room audio behind despite omitting `--keep`. Use `TemporaryDirectory` and guaranteed cleanup.

**NIT**

- Update stale operational comments: HDA still describes opt-in capture and a 64-KiB ring; GMA describes itself as read-only; the installer’s t9 comment claims `gfxpayload=text` prevents the graphics problem that the later header change actually fixed.
- The SSH window-change log still says `80x25` although the packet uses runtime dimensions.

I found no concrete on-target grid-index overflow: mouse positions are clamped, each SSH session resizes its terminal, and the DMA ring’s four-byte alignment keeps its slices bounded. Both home and SSH continue servicing bmctl, and idle propagates back to main’s reset path. The earlier aperture-mapping and console-rejection rollback fixes are present. None of that establishes hardware watchdog or display recovery beyond the supplied evidence.
